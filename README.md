# Jamila Khalifa

**Desenvolvedora web · Ciência, filosofia e tecnologia**

Desenvolvo sites, plataformas web, portfólios e soluções digitais para profissionais, pequenos negócios e projetos educacionais. Meu trabalho parte de uma pergunta: **como transformar uma necessidade real em uma experiência simples de usar?**

Sou graduanda em Ciências Biológicas e encontro na ciência uma forma de observar, na filosofia um convite a questionar e na tecnologia um caminho para construir.

Nos meus projetos, combino desenvolvimento frontend e backend, organização de informações, identidade visual e experiências responsivas. Também exploro inteligência artificial, automações e integrações entre diferentes serviços para criar ferramentas que vão além da apresentação visual.

## O que orienta meu trabalho

- Compreender o objetivo do projeto e as necessidades de quem vai utilizá-lo.
- Transformar problemas reais em soluções digitais funcionais.
- Desenvolver interfaces responsivas, intuitivas e visualmente coerentes.
- Integrar frontend, backend, bancos de dados e serviços externos.
- Explorar inteligência artificial e automações quando agregam valor à experiência.
- Valorizar a organização, a acessibilidade e a manutenção dos projetos.

> Criar começa por questionar: olhar de outro modo para o que existe abre espaço para o que pode existir.
